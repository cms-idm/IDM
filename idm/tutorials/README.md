# idm tutorials

Hands-on, runnable walkthroughs of the `idm` analysis workflow. Open in Jupyter with the
`IDM (LCG_107 Py3.11)` kernel (see `../../SETUP_Run3.md`); run from the repo root.

- `01_workflow_walkthrough.ipynb` — the named-config flow end to end: load an ntuple → look at
  objects → see what to edit where (`idm/definitions/`) → run `IdmProcessor` → make a CMS-style plot.

More tutorials (distributed running, provenance, real selections) are added as the analysis grows.
